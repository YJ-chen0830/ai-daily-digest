## 📌 頭版焦點

### morluto/rea — 用 AI Agent 做逆向工程，直達二進位層

逆向工程向來是資安研究的重型武裝，需要熟練操作 Ghidra、IDA、Hopper 等工具，還得看得懂 Assembly。**REA**（Reverse Engineer Anything）試圖把這個門檻拉低：它以 MCP（Model Context Protocol）為骨架，把各種分析工具包裝成 Agent 可呼叫的介面，讓你直接用自然語言描述目標（「這個 App 的付費驗證機制是怎麼做的？」），由 Agent 協調 Ghidra 或 Hopper 完成靜態分析、反組譯，並回傳含有證據鏈的結論。

對生態系而言，影響有兩個方向。正面是：CTF 選手與資安研究員可以大幅縮短初步偵察的時間；Electron App、.NET Assembly、JavaScript bundle 的分析路徑也首次被整合進同一介面。負面的討論則幾乎可以預期——降低逆向門檻意味著同樣降低惡意分析的成本，這點 README 沒有正面說明。

從數字看，今日單日新增 25,599 顆星，總星數已達 11.97 萬，爆發速度異常。專案創立於今年 4 月，成長曲線暗示有明顯的行銷推力在背後。核心功能本身值得關注，但成熟度與穩定性仍需實際驗證。

### [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design)　⭐ 51,011（今日 +1,083）
- **一句話定位**：給 Claude Code、Copilot、Cursor 等 AI Coding Agent 用的圖表繪製技能，輸出自給自足的 HTML+SVG 檔案。
- **能拿來做什麼**：用自然語言描述架構圖、時序圖、象限圖等 44 種圖表類型，Agent 自動生成一個雙擊即可在瀏覽器開啟的 `.html` 檔；支援從 draw.io、Mermaid、Excalidraw 匯入，也可匯出 PNG/SVG。可抓取指定網站的品牌色與字型，使後續圖表風格一致。
- **編輯點評**：標題刻意寫「No Mermaid slop」，就是要跟 Mermaid 自動生成的素樸線圖做對比，主打視覺質感。完全本地渲染、無需雲端服務是亮點。但 51K 星對一個 HTML 為主語言的工具而言數字偏高，可能有社群炒作成分；實際排版能否真正脫離「slop」範疇，仍需自行測試。

### [lyogavin/airllm](https://github.com/lyogavin/airllm)　⭐ 36,774（今日 +548）
- **一句話定位**：無需量化、蒸餾，讓 70B 以上大模型在單張 4GB 顯卡上跑起來的推理框架。
- **能拿來做什麼**：透過逐層串流（layer streaming）技術，將模型權重分批載入 GPU，避免一次性佔滿 VRAM。README 聲稱支援 Kimi K3（2.8T 參數）在 3.72GB VRAM 下運行、DeepSeek-V3（671B）約需 12GB。2026 年 9 月新增訓練支援，Qwen3.8-Flash-Next（125B）可在 6GB 內做 LoRA fine-tune。
- **編輯點評**：概念可行，逐層載入是已知技術，但速度代價極大——推理速度會遠低於正常部署。README 中穿插了兩個明顯的廣告連結（AI 遊戲 Sprite 生成器、AI 換臉工具），降低了文件的可信度。適合資源極度受限的研究用途，不建議用於生產。

### [Ayzzz123/mcd-coupon-strategist](https://github.com/Ayzzz123/mcd-coupon-strategist)　⭐ 174
- **一句話定位**：基於麥當勞中國 MCP 的點餐成本優化 Agent Skill，核心在於算出「快過期的券價值多少錢」。
- **能拿來做什麼**：拉取當前門店實時菜單與帳戶優惠券，枚舉所有點餐組合並透過 MCP 的 `calculate-price` 真實計算價格（而非估算）；另分析歷史訂單找出消費習慣的改善空間，並主動標記即將過期的券的「沉默成本」。

## 收盤註記

今日清單有一個明顯共同特徵：**MCP（Model Context Protocol）正在成為 Agent Skill 生態的事實整合標準**，從逆向工程（REA）到圖表生成（diagram-design）、麥當勞點餐（mcd-coupon-strategist），都以 MCP 為連接層，暗示 Anthropic 的這套協議正在沉澱為基礎設施而非話題。其次，**本地優先、資料自主**成為多個專案（Aurelio、wx-bot）的差異化賣點，顯示隱私敏感場景的需求仍未被雲端服務滿足。值得注意的是，今日有多個極新倉庫（創立不足一週）出現在清單中，星數成長模式偏陡，讀者在採用前應保持觀望。
