## 📌 頭版焦點

### alibaba/open-code-review — 阿里巴巴的 Code Review 軍火庫正式開源

在 AI coding agent 百花齊放的當下，程式碼品質卡控的缺口始終存在。`open-code-review` 是阿里巴巴將內部使用兩年以上、服務過數萬名開發者的 AI code review 工具正式開源的成果，以 Go 撰寫，以 CLI 形式運作。

其架構設計值得關注：它並非單純把 diff 丟給 LLM 了事，而是採用「確定性管線 + LLM Agent」的混合架構——內建針對 NPE、執行緒安全、XSS、SQL Injection 等常見缺陷的微調規則集，由確定性規則先做精準篩查，LLM 再處理難以規則化的語意層問題。這種設計在控制誤報率與 token 成本上有明顯優勢。

支援 OpenAI 與 Anthropic 相容介面，並已整合 Claude Code、Codex、Cursor 等主流工具鏈。它能精確標注到行級別的評論，而非含糊的段落建議。目前在 GitHub 累積超過 1.4 萬 star，今日單日新增 832，熱度相當實在。

對於已在用 AI agent 寫程式、但苦於 review 品質參差不齊的團隊，這是目前開源生態中最具規模化背書的選項之一。

### [citrolabs/ego-lite](https://github.com/citrolabs/ego-lite)　⭐ 4,837（今日 +900）

- **一句話定位**：讓 AI agent 與你共用同一個已登入的瀏覽器，各自在獨立 Space 操作，互不干擾。
- **能拿來做什麼**：將瀏覽器的登入狀態直接暴露給 Codex、Claude Code 等 agent，讓 agent 執行網頁自動化任務時無需另外設置登入流程，同時你的 tab 保持獨立。
- **編輯點評**：相較於 browser-use 等框架需要獨立驅動一個瀏覽器實例，ego-lite 主張「共用瀏覽器」的設計概念確實有差異化。不過目前僅支援 macOS，Windows/Linux 還在 roadmap 中。今日 +900 star 漲幅可觀，成立才三個多月，成熟度有待觀察——尤其是安全模型（agent 可以存取你所有的 session 這件事）需要仔細評估。

### [CoreBunch/Instatic](https://github.com/CoreBunch/Instatic)　⭐ 5,792（今日 +888）

- **一句話定位**：自架型視覺化 CMS，輸出乾淨的靜態 HTML，定位為 Webflow/Framer/WordPress 的開源替代方案。
- **能拿來做什麼**：用 Bun 單一伺服器跑完整個網站建置流程——視覺編輯器、內容管理、媒體、表單、外掛、發布——後端支援 SQLite 或 Postgres，可一鍵部署至 Railway 或 Render。
- **編輯點評**：「不留 runtime 痕跡的靜態輸出」是其核心賣點，對比大多數 page builder 輸出的 div soup 確實是痛點解法。四月底才建立，今日 +888 star，README 宣稱功能齊全但成熟度仍需實測驗證。外掛系統、多使用者協作等功能的穩定性，僅從 README 無法確認。

### [pbakaus/impeccable](https://github.com/pbakaus/impeccable)　⭐ 50,826（今日 +413）

- **一句話定位**：給 AI coding agent 的設計語言規範工具，提供 23 條指令與 60 條確定性設計檢測規則。
- **能拿來做什麼**：在 Claude Code 等工具中透過 `/impeccable init` 建立專案設計規範文件，後續用 `polish`、`audit`、`critique` 等指令約束 AI 生成的前端設計風格，避免「Inter 字型 + 紫藍漸層 + 圓角卡片」的千篇一律輸出。
- **編輯點評**：5 萬+ star 說明這個痛點是真實的。60 條確定性規則不依賴 LLM 與 API key 即可執行，架構思路清晰。本質上是 prompt 工程 + 靜態 linter 的組合，對真實設計多樣性的改善程度仍取決於使用者如何填寫 `DESIGN.md`。

### [OtterMind/Chat2DB](https://github.com/OtterMind/Chat2DB)　⭐ 27,228（今日 +398）

- **一句話定位**：支援 30+ 資料庫的跨平台 SQL 工作台，整合自帶 AI 助手（自備模型）。
- **能拿來做什麼**：替代 DBeaver/Navicat/DataGrip，在同一介面處理 SQL 編輯、執行、自動補全、資料視覺化、ER 圖、import/export，AI 功能支援自然語言轉 SQL，支援接入自選模型，並附帶 MCP 支援的 CLI。
- **編輯點評**：專案自 2023 年起累積逾 2.7 萬 star，是本清單中歷史最久的工具，功能廣度紮實。「自備 AI 模型」的設計讓企業使用者有資安控制空間，但核心後端以 Java 撰寫，對部分輕量化使用場景而言部署成本略高。

## 收盤註記

今日清單最顯著的訊號是：AI agent 的基礎設施競爭正在快速分層——瀏覽器層（ego-lite）、code review 層（open-code-review）、操作台層（BossConsole、Cindy）各自卡位，且多數專案誕生不超過三個月。阿里巴巴的 open-code-review 是今日唯一有規模化生產驗證背書的工具，其混合架構設計也是目前 AI code review 開源方案中最具參考價值的範本。值得警惕的是，今日有三個專案在建立不到一週內即登上榜單，star 暴漲速度遠超程式碼成熟度，讀者應以「看 demo 再說」的態度評估。
