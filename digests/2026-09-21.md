## 📌 頭版焦點

### [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill)

Cloudflare 將其內部漏洞發現系統的核心組件以開源形式釋出，這個「coding-agent skill」能夠把任何支援 skill 架構的 AI coding agent 轉化為系統性的安全稽核員。它不是單純丟給 LLM 一句「幫我找漏洞」，而是設計了六個結構化階段：從架構偵察、覆蓋率驅動的漏洞獵尋、候選驗證，到最終的獨立記錄核查，每個環節都有獨立的 agent 負責，並以機器可讀的 JSON schema 輸出結果，避免單一 agent 的確認偏誤（confirmation bias）。

最值得注意的是其「anti-hallucination」設計理念：findings 被強制分為 `confirmed`、`needs_validation`、`rejected` 三類，`confirmed` 必須附有完整的原始碼追溯與可觀察結果，`needs_validation` 則明確標記尚未解決的事實爭議。多次執行具累加性，不會把舊的未驗證結果誤算為已覆蓋範圍。

對生態系的潛在影響在於：這是一個可被整合進 CI/CD 的安全稽核原語，而非另一個掃描器黑盒。今日單日暴增 2428 顆星，反映資安社群對「可解釋 AI 稽核」的強烈需求。
