## 📌 頭版焦點

### PrimeIntellect-ai/prime-agent — 自我改進的 RLM Agent，試圖重新定義長時間自主任務

[prime-agent](https://github.com/PrimeIntellect-ai/prime-agent) 今日單日新增 2356 顆星，是本期最受關注的新興專案。它的核心概念是 **RLM（Recursive Language Model）**：把 context 當作可操作的變數，把工具呼叫與子 Agent 當作函式，全跑在一個持久的 IPython REPL 裡。這不只是又一個「包一層 LLM 的 CLI 工具」——其 **Continual Harness** 機制讓 Agent 可在會話之間留存 prompt 補充狀態、記憶、技能定義，並透過 `/refine` 指令做有根據的小幅修正，支援 rollback，且不觸動基礎系統 prompt。

對生態系的潛在影響在於：它試圖把「Agent 自我改良」從研究論文搬到可執行的開源工具上。這個方向本身仍屬高風險實驗領域，RLM 相關論文（arxiv 2605.09998）是否能在工程實踐中站穩，尚待社群驗證。專案以 TypeScript 為主，5 月才建立，文件尚在補充中——大量 star 有部分來自 PrimeIntellect 研究社群的號召，成熟度需謹慎評估。但若其「技能即可匯入 Python 套件」的設計真能運轉，對長時間 coding agent 工作流的影響值得持續觀察。

## 收盤註記

今日候選清單有一個顯著結構：「Agent Skills」這個詞彙已形成一個小型生態，從 Addy Osmani 的個人專案到 Google 官方都在搶佔這個命名，配合 `npx skills add` 的統一安裝介面，隱約可見某種平台標準化的企圖。更值得警惕的是，同樣的熱門標籤也被用於包裝惡意軟體（oliverb-io1902e8/agent-skills-collection），顯示開源生態的聲譽風險正隨著 agent 話題的火熱而同步升高，工程師在安裝任何「skills」套件前應做基本的程式碼審查。KADATH 和 NeuroArxiv 是今日少數真正嘗試解決特定工程問題的早期專案，雖然星數不高，但思路比大多數 prompt 模板集合更有深度。
