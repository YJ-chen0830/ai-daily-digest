## 📌 頭版焦點

### mattpocock/skills — AI 代理技能庫的事實標準競爭者

`mattpocock/skills` 由 TypeScript 教學界知名人物 Matt Pocock 所建立，定位是「真正工程師用的 agent skills」，總星數已達 25.5 萬顆，今日單日新增 2,207 顆，成長動能仍在高點。

這個專案的核心概念不是要取代你對 AI 的控制權，而是提供一批「小型、可組合、可修改」的 skill 指令集，讓 Claude Code、Codex 等 agent 更有紀律地工作。它直接批評 GSD、BMAD、Spec-Kit 等流程導向框架「把主導權從工程師手中拿走」，改走模組化路線。

安裝方式分兩種哲學：透過 Claude Code 官方 plugin marketplace 訂閱（更新自動推送、唯讀）；或用 `npx skills@latest` 複製可編輯檔案到本地（自己 fork、自己改）。這個雙軌設計本身就是一種立場聲明：要訂閱標準品，還是要自己動手。

從生態系角度看，`skills.sh` 作為一個通用安裝工具的出現，正在形成類似 npm 的 skill 套件管理機制。若此標準鞏固，未來 agent skill 的分發方式可能從各廠商私有格式統一到這個 Markdown-based 規範，對整個 AI coding agent 生態的影響不容忽視。

## 收盤註記

今日十條精選中，有六條明確圍繞 Claude Code 的 agent skill 生態——skills.sh 作為分發基礎設施的角色正在鞏固，而 Markdown-based skill 正快速成為一種事實上的跨平台格式。值得警惕的是，這波熱潮中不乏「把既有概念包成 skill」的低門檻套利，如 YAGNI 原則、AI 文字去味等，技術含量參差。另一個觀察：本地推論接 agent 工具（Magnitude）與輕量遠端開發工具（remote-installer）同日出現，顯示工程師正在積極補足「AI agent 在本地跑起來」的最後一哩路基礎設施。
