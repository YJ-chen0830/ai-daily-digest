## 📌 頭版焦點

### VoiceStudio：本地語音克隆的 ElevenLabs 平替，⭐ 75,995

`debpalash/VoiceStudio` 是目前規模最大的開源語音合成框架之一，定位為 ElevenLabs 的完全本地替代方案，支援語音克隆、語音設計、影片配音、聽寫、轉錄與有聲書製作，宣稱支援 646 種語言。底層引擎預設採用 k2-fsa/OmniVoice，同時提供多引擎切換機制，並支援 CUDA 與 Apple MLX 加速。

為何值得關注？ElevenLabs 近年在 API 定價與使用條款上爭議不斷，替代需求真實存在。VoiceStudio 將 Local API 與 MCP 整合一併納入，意味著可直接接入 agent 工作流，不只是單一功能工具。採用 AGPL-3.0 授權，商業使用需注意 copyleft 傳染性。

成熟度方面，約六個月前建立、目前星數接近 76k，成長速度異常，有行銷聲量助推的跡象。文件結構看起來完整（有 CI badge、release 版本、Discord 社群），但 646 種語言的品質差異、各引擎穩定性，以及本地執行的硬體門檻，仍需實測才能確認。對有語音隱私顧慮或成本壓力的團隊而言，值得列入評估清單。

## 收盤註記

今日上榜的 10 個專案中，有半數直接或間接繞著 Claude Code 生態系打轉——官方 Plugin 目錄、求職框架、Blender 插件都明確標榜 Claude Code 整合，顯示 Anthropic 正在主動拉攏第三方生態，plugin marketplace 的格局已初具雛形。另一條明顯主線是「本地優先、訂閱替代」：VoiceStudio 對標 ElevenLabs、ai-job-search 把 API 跑在自己機器上，隱私與成本壓力正推動開源社群系統性地拆解 SaaS 訂閱模式。值得注意的是，今日多個高星專案的建立時間均不超過八個月，快速衝星現象持續，讀者在採用前應以實際 benchmark 與文件完整度作為評估標準，而非單看 star 數。
