## 📌 頭版焦點

### [lightpanda-io/browser](https://github.com/lightpanda-io/browser) — 用 Zig 重寫的 headless 瀏覽器，針對 AI 自動化場景

Headless Chrome 是當前 AI agent 做網頁自動化的事實標準，但它從未為大量並發的 agent 工作負載設計。Lightpanda 的切入點直接：不 fork Chromium、不打 WebKit 補丁，從零用 Zig 重寫一顆瀏覽器引擎，並相容 CDP（Chrome DevTools Protocol），意味著 Playwright 和 Puppeteer 的指令多數可以直接切換。

根據其提供的基準測試數字（AWS EC2 m5.large，爬取 933 個真實頁面）：尖峰記憶體約 123MB 對比 Headless Chrome 的 2GB，執行時間 5 秒對比 46 秒，差距顯著。但需注意：這份 benchmark 由專案本身發布，尚未見到獨立第三方驗證；JavaScript 相容性與 CSS 渲染覆蓋率也僅從 README 無法確認。

對 AI infra 生態系的潛在影響是：如果資源消耗數字成立，在單機上跑幾十個並行 agent 做網頁任務的成本將大幅下降，對雲端 scraping 服務也構成價格壓力。專案 2023 年創立，目前仍發布為 nightly，表示穩定性還需觀察。

## 收盤註記

今日最顯著的趨勢是**手機 agent 的密集冒出**：Mika、DSH-Android、AnyModelBot 三個專案在同一週內相繼建立，都在嘗試讓 LLM 透過無障礙服務操控 Android app。這個方向技術路徑清楚，但 Android 版本碎片化與無障礙 API 的不穩定性是現實障礙，目前幾個專案均屬極早期。另一個觀察是 **Claude Code 周邊生態持續膨脹**——claude-mem、Claude Code Game Studios 都是依附 Anthropic 工具鏈的衍生專案，過高的星數有部分可能來自 Claude 社群的話題效應，技術深度需獨立驗證。
