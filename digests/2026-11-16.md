## 📌 頭版焦點

### GoogleChrome/modern-web-guidance-src

這個專案解決的問題直指 AI 輔助開發的核心痛點：LLM 的訓練資料充斥著過時的 Web 程式碼，導致 coding agent 習慣性地生成老舊甚至冗餘的 JavaScript，忽略了現代瀏覽器原生就已提供的高效能 API。**Modern Web Guidance** 的解法是將 Chrome、Edge、Firefox 與 MDN 團隊共同維護的「最佳實踐技能集」直接注入 coding agent 的 context，讓它在生成程式碼時能主動偏向現代 Web 平台方案。

更值得注意的是這個專案的組織背書：由四大主流瀏覽器陣營聯合維護，不是哪家廠商的單邊行銷，而是跨競業的規格協作，在開源生態中實屬罕見。實際使用門檻很低——一行 `npx modern-web-guidance@latest install` 即可，也支援掃描既有程式碼庫找出待現代化的遺留模式。

從生態影響來看，若各主流 coding agent 廠商將此技能集納入預設配置，可能實質加速 Web 開發社群拋棄 jQuery 時代遺留慣例的速度。當然，技能集的覆蓋範圍與更新頻率能否跟上瀏覽器規格演進，才是長期成敗的關鍵。今日單日新增 1,219 顆星，聲量顯著。

## 收盤註記

今日精選集中呈現一個清晰趨勢：**為 coding agent 量身打造的配套基礎設施**正快速成形——從注入現代 Web 知識（Modern Web Guidance）、瀏覽器控制（chrome-devtools-mcp）、Code Review（open-code-review），到人類監督介面（plannotator），各環節都在補完 agent 工作流的缺口。值得警覺的是，今日出現三個幾乎相同的 fork 帳號操縱 GitHub Trending，提醒讀者對 star 數字的可信度保持懷疑；阿里巴巴 open-code-review 在不到半年內累積 5.2 萬顆星，同樣需要更多時間驗證其聲稱的生產規模。
